# Wazuh SOC Home Lab

A hands-on cybersecurity lab built to explore Security Information and
Event Management (SIEM), endpoint monitoring, security event analysis,
and File Integrity Monitoring (FIM) using Wazuh.

**Project status:** In Progress\
**Category:** Cybersecurity \| Blue Team \| SOC \| SIEM

## Overview

This project documents my experience building and configuring a Wazuh
security monitoring lab using VirtualBox, Ubuntu, and a Windows
endpoint.

The objective is to understand how a SIEM platform collects endpoint
information, monitors system activity, and helps investigate security
events.

The lab also explores File Integrity Monitoring (FIM) and the
verification of file-related security alerts.

## Lab Architecture & Environment

This lab uses a virtualized environment to explore endpoint monitoring,
event collection, and alert investigation using Wazuh. Ubuntu hosts the
Wazuh monitoring components, while Windows 10 serves as the monitored
endpoint.

### Environment Specifications

  Component               Configuration
  ----------------------- -----------------------------------------------------
  Host Operating System   Windows 11
  Hypervisor              Oracle VirtualBox 7.2.12
  Wazuh Manager           Ubuntu 24.04.4 LTS
  Wazuh Version           4.12.0 RC1 
  Monitored Endpoint      Windows 10 Home 22H2
  Windows Build           19045.2965
  Virtual Network         NAT Network
  Network Address Range   `10.0.0.0/24`

### Architecture Overview

``` text
             Windows 11 Host
                    |
            Oracle VirtualBox
                    |
              NAT Network
                    |
          +---------+---------+
          |                   |
          v                   v
      Ubuntu VM          Windows 10 VM
    Wazuh Manager         Wazuh Agent
          |                   |
          |<------------------|
          |
    Wazuh Dashboard
    Security Alerts
    Event Analysis
```

**Component roles:** - **Ubuntu VM:** Runs the Wazuh monitoring
infrastructure and provides access to the security dashboard. -
**Windows 10 VM:** Generates endpoint telemetry collected by the Wazuh
agent. - 
**VirtualBox NAT Network:** Provides network connectivity
between the virtual machines according to the configured network and
firewall rules.

The lab is designed to monitor endpoint activity, analyze security
alerts, and understand how a SIEM platform supports defensive security
operations.

For installation procedures, agent configuration, and connectivity
verification, refer to the dedicated setup documentation.

## Setup and Configuration

The lab setup involves installing and configuring Wazuh, connecting the
Windows endpoint to the manager, and verifying communication through the
dashboard.

The main configuration stages include:

1.  Preparing the virtual machines and configuring their network
    connectivity.
2.  Installing the Wazuh manager, indexer, and dashboard on Ubuntu.
3.  Installing and configuring the Wazuh agent on Windows 10.
4.  Registering the endpoint with the Wazuh manager.
5.  Verifying agent connectivity and the collection of security events.
6.  Reviewing alerts and investigating relevant endpoint activity.

**Detailed setup guides:** - [Installation and
Configuration](docs/installation-and-configuration.md) - [Agent
Onboarding](docs/agent-onboarding.md) - [Lab
Architecture](docs/lab-architecture.md)

## File Integrity Monitoring

File Integrity Monitoring is the current focus of this project. It is
used to detect changes to selected files and directories on the Windows
endpoint.

The test uses a dedicated, non-sensitive directory on the Windows
endpoint:

1.  Configure Wazuh to monitor the directory.
2.  Restart the agent if required by the configuration change.
3.  Create a test file.
4.  Modify the file.
5.  Delete the file.
6.  Check the Wazuh dashboard for the corresponding events.
7.  Record the results and supporting screenshots.

The FIM test will be marked complete after the expected events have been
verified.

For the detailed procedure and test evidence, see [File Integrity
Monitoring](docs/file-integrity-monitoring.md).
